# موقع البورتفوليو والسيرة الذاتية التفاعلية لـ أسامة 🚀
**طالب كلية الحاسبات والذكاء الاصطناعي | مهتم بالـ AI والموبايل**

تم تصميم هذا الموقع خصيصاً كبديل عصري واحترافي للسيرة الذاتية (CV) لتسويق مهاراتك وخبراتك أمام شركات التوظيف وأصحاب المشاريع والعملاء بأحدث معايير تصميم الويب العالمية.

---

## 🌟 أبرز مميزات الموقع:
1. **تصميم عصري وفخم (Modern Glassmorphism & Cyber Aesthetics):** متناسق مع صورتك الشخصية بلمسات لونية جذابة وخلفيات تفاعلية.
2. **صورتك الشخصية الرسمية:** مدمجة في واجهة الموقع والهيدر والسيرة الذاتية بجودة عالية.
3. **ترسانة المهارات شاملة ومصنفة:**
   - **بايثون (Python):** تطبيقات الذكاء الاصطناعي، معالجة البيانات، والتعلم الآلي.
   - **أساسيات C# و C++:** البرمجة الكائنية OOP وهياكل البيانات وحل المشكلات.
   - **HTML5:** هيكلة صفحات الويب والتصميم المتجاوب.
   - **الذكاء الاصطناعي وتعلم الآلة (Machine Learning):** بناء وتدريب وتطوير النماذج.
   - **شبكات الحاسوب (Computer Networks):** البروتوكولات، معمارية OSI، وتوجيه البيانات.
   - **سيرفر لاب (Server Lab):** إدارة السيرفرات وقواعد البيانات وتجهيز بيئات العمل.
4. **مجالات الشغف والاهتمام المستقبلي:**
   - هندسة الذكاء الاصطناعي (AI Engineering).
   - تطوير تطبيقات الموبايل الحديثة (Mobile Applications).
   - الأنظمة المتصلة وهندسة الشبكات.
5. **تواصل واتساب فوري وتفاعلي:**
   - زر واتساب عائم مباشر برقمك: `01145619853`.
   - أداة إنشاء رسالة واتساب مسبقة التجهيز (طلب تدريب، مشروع، استفسار) بنقرة واحدة.
   - زر نسخ رقم الهاتف والواتساب بنقرة واحدة مع إشعار فوري.
6. **دعم ثنائي اللغة كامل (عربي RTL / إنجليزي LTR):**
   - زر تبديل فوري في القائمة العلوية يسمح لأي مسؤول توظيف عربي أو أجنبي بقراءة السيرة بلغته المفضلة.
7. **طباعة / تصدير السيرة الذاتية كـ PDF بنقرة واحدة:**
   - زر "تحميل / طباعة السيرة (CV)" يحول الموقع تلقائياً إلى سيرة ذاتية تنفيذية أنيقة باللون الأبيض والأسود مناسبة للطباعة وحفظها كملف PDF.
